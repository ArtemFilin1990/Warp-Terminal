# Warp-Terminal

Warp Terminal — это быстрый современный терминал, созданный для программирования с использованием агентов.

## Основные возможности

### Режим работы с агентом

Переключение между чистым терминалом для ввода команд и специальным режимом диалога для многоэтапных рабочих процессов с участием агента. Реализовано в модуле [`src/agent`](src/agent/).

- `TerminalMode::Command` — стандартный терминальный режим для ввода команд.
- `TerminalMode::Dialogue` — режим диалога с агентом для многошаговых сценариев.
- Переключение через `AgentMode::toggle()` или `AgentMode::enter_dialogue(agent_id)`.

### Современный пользовательский интерфейс терминала

Реализовано в модуле [`src/terminal`](src/terminal/) на языке Rust.

- **Перемещение курсора и навигация по блокам** — `InputBuffer` поддерживает движение курсора влево/вправо/вверх/вниз; `BlockNavigator` предоставляет навигацию по истории выполненных команд.
- **Многострочное редактирование** — `Shift+Enter` вставляет перевод строки без отправки команды; `Enter` отправляет команду.
- **Подсветка синтаксиса** — `Highlighter` разбивает строку на токены (ключевые слова, строки, числа, комментарии, операторы).
- **Автодополнение** — `AutocompleteEngine` предлагает варианты по введённому префиксу.

### Редактор кода

Реализовано в модуле [`src/editor`](src/editor/).

- **Дерево файлов** — `FileTree` загружает директории и поддерживает раскрытие/скрытие узлов.
- **Редактор кода с поддержкой LSP** — `LspClient` хранит диагностики (ошибки, предупреждения) и предоставляет их по номеру строки.
- **Интерактивная проверка кода** — ошибки и предупреждения доступны через `LspClient::diagnostics_at_line`.

### Интеграция с агентами для написания кода

Реализовано в модуле [`src/integration`](src/integration/).

- **Голосовой ввод** — `VoiceInput` управляет состояниями `Idle → Listening → Processing → Idle` и сохраняет транскрипты.
- **@-selection** — `SelectionRegistry` позволяет привязывать файлы, текст и изображения к меткам `@label`, которые автоматически раскрываются в промптах.
- **Поддержка агентов** — совместимо с Oz, Claude Code и Codex через `AgentBackend`.
